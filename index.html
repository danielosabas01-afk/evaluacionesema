Por qué la aplicación completa todavía no arranca aquí

GitHub Pages sirve sitios estáticos; no ejecuta el servidor Python ni la base SQLite que necesita EMA para importar archivos, guardar cambios y compartir un historial común. No mostramos una pantalla falsa diciendo que esas funciones ya funcionan. El siguiente paso de despliegue es conectar un servidor Python persistente y apuntar esta interfaz a él.
